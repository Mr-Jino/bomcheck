# 一台卖 4000 的车载监控终端，拆开是什么

> 本文所有成本数字都由 `bomcheck` 引擎按 `pricebook.json` 现算，不是拍脑袋的估计。
> 复现命令在文末。**不点名任何厂商**——要说的不是某一家，是这一整类产品的定价逻辑：
> 硬件那部分是能算清的，但从来没人把它单独摆出来。

---

## 一、结论

按本仓库的价表口径，一台「Cat.1 网关 + 10 寸屏 + 4 路摄像头 + 串气路执行」的整机：

| 口径 | 金额 |
|---|---|
| 物料费（19 个件，含采购损耗） | **￥643.37** |
| 加工费（贴片 820 点 + 手焊 55 点 + 组装 22 分钟） | ￥42.99 |
| 测试 + 认证摊销 + 包装 + 物流 + 不良 + 摊销 | ￥139.97 |
| **出厂成本** | **￥826.33** |

市面同类整机常见报价 **￥4000 / 台**。按 1000 台批量算：

**报价 ÷ 出厂成本 = 4.84 倍；报价 ÷ 物料成本 = 6.22 倍。**

这不是说它"暴利"就该骂——服务、算法、流量、安装都要钱。要看的是：**这些钱分别占多少，而卖方从不把它们分开报。**

## 三、三个架构真相

### 1. 这块网关板，压根不碰视频

把带宽算一下就知道：

- Cat.1 上行 **5 Mbps**
- 4 路 720p、H.264、1.5 Mbps/路 → **6 Mbps**
- 换成 1080p、4 Mbps/路 → **16 Mbps**

**装不下。** 不是"为了省流量所以不全传"，是物理上做不到。

所以那块写着 `THROTTLE CTRL` 的控制板上，GD32 只干三件事：收云端指令、驱动继电器、上报坐标和告警 JSON。**它连一路视频都不解码。**

### 2. 视频在另一块板子上，于是有两套系统

4 路摄像头接的是屏幕后面那块板（视频 SoC + SD 卡槽 + WiFi）。它自己存、自己截片段，通过 WiFi 递给网关板，网关板再用 4G 发出去。

结果就是：**新装的 ADAS 摄像头画面，在车上那块屏里显示不出来。** 因为屏幕归旧的行车记录仪那套系统管，两套线、两套录像、两套管理界面。

这不是"设计取舍"，是两套东西拼在一起、没打通。

### 3. 板子只是手，脑子在云端

疲劳判定、视线角度、碰撞预警——这些算法 100% 跑在服务器上。设备端的算力只够执行"收到指令 → 继电器闭合"。

这带来两个后果：

- **断网就等于断功能。** 隧道、山区、地库，判定能力直接归零，只剩本地录像。
- **算法看不见、摸不着、也没法验。** 误报率多少、漏报率多少、模型更新过几次——客户拿不到任何可核的东西。

## 四、"物理干预"这件事，得单独说

这类方案里有一种做法：**把原车气压刹车管剪开，串一个电磁阀进去**，用继电器控制开合，实现"远程/自动刹车"。

从工程角度看，这条链上有四个问题：

1. **原厂气路是标定过的。** 加一段管路 = 改变容积和流阻，刹车响应曲线跟着变，原厂标定作废。
2. **电磁阀是单点失效件。** 卡死、进水、线圈老化，任一种都可能导向两个方向：该刹不刹，或者不该刹却抱死。
3. **没有冗余。** 商用车的 EBS/ABS 是冗余设计的，一串电磁阀把冗余抹掉了。
4. **责任无法切割。** 一旦出事，设备商说"我只提供信号"，安装队说"我按图纸接线"，车队说"我买的成品"。

而"线束保护、烧了只烧设备"这种说法，回避了一个事实：**串在气路里的阀，烧的不只是设备。**

真要干预，非侵入的路子是有的：读 CAN 总线拿车速/刹车信号，用声光 + 座椅震动提醒司机。**这不酷，但它不动原车的物理结构。**

## 五、那 4000 块都去哪了

把一台的价拆开（区间为常见区间，不是精确数）：

| 项 | 金额 | 能不能核 |
|---|---|---|
| 硬件出厂成本 | ￥826 | **能**，就是本文这张表 |
| 安装人工（走线、接管、标定、返工） | ￥200–400 | 半能，看工时 |
| 4G 流量（3 年） | ￥180–360 | 能，运营商有价 |
| 平台算力 + 存储（3 年） | ￥? | 不能，没有公开口径 |
| 售后/换机预留 | ￥? | 不能 |
| 剩下的 | ￥? | 不能 |

**问题不在"剩下的"有多少，在于它和硬件捆成一个数报给你。**

客户拿两个品牌的 4000 和 3800 比价，比的其实是两笔算不清的服务费——硬件那部分明明是能算的，但没人给你拆。

按 5000 台规模做个算术（纯假设，不代表任何真实合同）：硬件 ￥826 × 5000 ≈ **413 万**；按 ￥4000 报价则是 **2000 万**。

## 六、那我该花多少钱

同一个洞口——不对，同一个需求，三种做法：

| 档位 | 装什么 | 出厂成本 | 按档报价 |
|---|---|---|---|
| 精简 | 不装屏、不装摄像头、不串气路。只读车、上传、声光提醒 | **￥263.18** | ￥526.37 |
| 标准 | 本文这台：屏 + 4 路 + 气路执行 | **￥826.33** | ￥2,148.46 |
| 冗余 | 双 4G、双电源、光耦隔离、压铸车规壳、屏蔽线束，**刻意不装气阀** | **￥897.93** | ￥3,052.97 |

**冗余档比标准档贵 ￥71.6，但把"不坏"这件事买齐了，而且没动刹车管。**

钱该花在"不坏"上，不是花在"能刹车"上。这句话值 ￥71.6。

## 七、自己核一遍

```bash
pip install -e .
bomcheck check data/bom-terminal-std.json --quote 4000
bomcheck tiers data/bom-terminal-lite.json data/bom-terminal-std.json data/bom-terminal-rugged.json
```

价表 `pricebook.json` 是明文 JSON，按你自己渠道的询价改；改完再跑，倍数会跟着变。

**报价 ÷ 出厂成本** 超过 3 倍打红、**报价 ÷ 物料成本** 超过 4 倍打红——阈值也在价表里，你可以改，但改了就不是同一把尺了。

## 边界

- 价表是 1000 台批量的参考区间，不是任何一家的真实采购价。批量、账期、渠道不同，差 30% 很正常。
- 本文不主张某一款产品"不该卖 4000"。它主张的是：**硬件成本应该被单独看见**，剩下的是服务费，服务费要有服务费的说明。
- 气路/刹车那节是工程推理，不是事故认定。本仓库不做安全认证，也不建议任何人照着自己改装制动系统。
- 文中所有具体型号（GD32F305、A7670C、TAU1114、RV1106……）都是公开市售元器件，价格可查。
