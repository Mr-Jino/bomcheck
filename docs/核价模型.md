# 核价模型

这份文档解释引擎里的每一个数字是怎么来的。所有参数都在 `pricebook.json`，改了就生效，不需要动代码。

---

## 一、九项成本

出厂成本 = 前七项加总 × (1 + 研发管理摊销率)

| # | 项目 | 算法 | 为什么单列 |
|---|---|---|---|
| 1 | 物料费 | Σ 数量 × 单价 × (1 + 类别损耗率) | 采购损耗按类别差很多，混一个平均数会算错 |
| 2 | 加工费 | 贴片点数×元/点 + 手焊点数×元/点 + 组装分钟×元/分钟 | 这三项的单价完全不同，压一起就没法谈价 |
| 3 | 测试费 | 测试分钟 × 元/分钟 | 很多 BOM 表压根漏了这行 |
| 4 | 认证摊销 | 认证一次性总额 ÷ 批量 | **小批量最容易被漏掉的一项** |
| 5 | 包装费 | 元/台 | 简单固定，但不该忘 |
| 6 | 物流费 | 元/台（到仓） | 同上 |
| 7 | 不良返修 | (物料 + 加工) × 不良率 | 只按物料加工计提，不含测试包装 |
| 8 | 研发管理摊销 | 前七项 × 摊销率 | 可设 0，但设 0 等于假装公司不花钱 |
| 9 | （报价） | 出厂成本 × 档位倍数，或用外部报价 | 见第三节 |

### 采购损耗率

| 类别 | 损耗 | 理由 |
|---|---|---|
| 芯片 | 2% | 静电、贴片抛料 |
| 模组 | 2% | 同上，焊盘大更难补 |
| 屏 | 3% | 易碎，运输破损 |
| 结构 | 5% | 划伤、氧化、开孔偏差 |
| 线束 | 3% | 压接不良 |
| 辅料 | 5% | 螺丝、标签的散失 |

**这些数不是行业标准，是常识区间。** 你的厂如果结构件损耗是 8%，改价表。

### 为什么认证必须摊销

一张 3C / 入网许可 / SRRC，一次性 3–5 万。做 5000 台，摊 7 元；做 200 台，摊 175 元。

不少小批量报价亏就亏在这：按 5000 台的单价报到 200 台的单子上，**认证费一项就是负毛利**。引擎里 `批量` 一改，这一项立刻跟着变，这是它最该做的事。

## 二、报价倍数 ≠ 利润率

这是整个核价里最容易算反的一处。

> 成本 1000，乘 2.6 报 2600，毛利率是 **61.5%**，不是 160%。

因为毛利率的分母是**报价**，不是成本：

```
毛利率 = (报价 − 成本) / 报价 = 1 − 1/倍数
```

| 倍数 | 毛利率 |
|---|---|
| 1.5 | 33.3% |
| 1.8 | 44.4% |
| 2.0 | 50.0% |
| 2.2 | 54.5% |
| 2.6 | 61.5% |
| 3.0 | 66.7% |
| 3.4 | 70.6% |
| 4.0 | 75.0% |
| 4.84 | 79.3% |

价表里三个档位默认是 **精简 2.0 / 标准 2.6 / 项目制 3.4**，分别对应「走量」「常规」「带交付的小批量项目」。

## 三、红旗阈值怎么定

引擎对「报价 ÷ 出厂成本」和「报价 ÷ 物料成本」两条线分别判：

| 判据 | 阈值 | 含义 |
|---|---|---|
| 报价 ÷ 出厂成本 | ≥ 3.0 红 | 硬件之外的钱已经是硬件的两倍，必须解释清楚那部分是什么 |
| 报价 ÷ 出厂成本 | 2.2–3.0 黄 | 常规偏高，问一句就够 |
| 报价 ÷ 出厂成本 | < 1.6 蓝 | 可能不含安装/服务，或者算漏了项——便宜得可疑 |
| 报价 ÷ 物料成本 | ≥ 4.0 红 | 连加工都没算进去就已经 4 倍，纯硬件口径不可能成立 |

另外两条软提示：

- **灰**：某一行单价高于价表参考价 1.5 倍 → 先查渠道，不是报价方的问题，是你自己采购被加价了。
- **注意**：BOM 里出现气阀 / 刹车 / 气路 / 电磁阀 → 提示这是非冗余物理改装，安全责任不在本工具的评估范围。

阈值可以改，但改了就不是同一把尺——两个方案要比，必须用同一份价表、同一套阈值。

## 四、价表怎么建

价表是这个工具唯一有壁垒的部分，也是唯一需要你亲自干活的部分。

1. **按规格建键。** 用型号码（`A7670C`、`GD32F305RET6`），不要用"4G 模块"这种描述——描述会漂，型号不会。
2. **填区间里偏保守的一头。** 1688 上标 38 元的模组，1000 台实拿往往 42–45。用能拿到的价，不用最便宜的那条链接。
3. **写备注。** 备注栏写"含税/不含税""MOQ 500""含运费"——三个月后你会感谢自己。
4. **类别别写错。** 类别决定损耗率，写错就退回默认 3%。
5. **一份价表只对应一个批量档。** 1000 台的价和 100 台的价不是一份表，分开放。

## 五、这个模型不做什么

- **不算模具费。** 开模是一次性几万到几十万，要不要摊、摊多少，看你的账怎么记。
- **不算研发人力。** `研发管理摊销率` 是个粗口径的比例，不是人力成本核算。
- **不算资金成本。** 账期 90 天和现结，是两个生意。
- **不判断产品该不该做。** 它只回答一个问题：**这个价，硬件部分值多少。**
