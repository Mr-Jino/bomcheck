# bomcheck · 拆秤

**硬件 BOM 核价器。** 一份 BOM 进去，九项成本出来，每项都带算式；再拿它去比对面那份报价。

## 先看一个数

一台在售的「Cat.1 网关 + 10 寸屏 + 4 路摄像头 + 串气路执行」营运车辆监控终端，卖 **¥4000**。

把它的 BOM 填进来，按 1000 台批量算：

| | |
|---|---|
| 物料费（19 个件，含采购损耗） | **¥643.37** |
| 加工费（贴片 820 点 + 手焊 55 点 + 组装 22 分钟） | ¥42.99 |
| 测试 / 认证摊销 / 包装 / 物流 / 不良 / 摊销 | ¥139.97 |
| **出厂成本** | **¥826.33** |

**报价 ÷ 出厂成本 = 4.84 倍。报价 ÷ 物料成本 = 6.22 倍。**

这不是说 4000 不合理——平台、算法、流量、安装都要钱。问题是：**这些钱从来不分开报。**

硬件那部分明明能算清，但没人给你拆。两个品牌报 4000 和 3800，你比的其实是两笔算不清的服务费。

完整拆解（含三个架构真相、气路改装的四个工程问题）：👉 [docs/拆解案例_车载终端.md](docs/拆解案例_车载终端.md)

## 它算哪九项

```
物料费       Σ 数量 × 单价 × (1 + 类别损耗率)
加工费       贴片点数×元/点 + 手焊点数×元/点 + 组装分钟×元/分钟
测试费       测试分钟 × 元/分钟
认证摊销     认证一次性总额 ÷ 批量        ← 小批量最容易漏的一项
包装费       元/台
物流费       元/台
不良返修     (物料 + 加工) × 不良率
研发管理摊销  前七项 × 摊销率
────────────────────────────────
出厂成本     以上加总
报价         出厂成本 × 档位倍数，或你给的外部报价
```

核心只有一句：**算不出来的项，不许用"大概"混过去。** BOM 行没写单价、价表里也查不到，程序直接报错，不给你一个猜出来的数。

## 用

```bash
# 核一份 BOM，附带外部报价
bomcheck check data/bom-terminal-std.json --quote 4000

# 三档并排：精简 / 标准 / 冗余
bomcheck tiers data/bom-terminal-lite.json data/bom-terminal-std.json data/bom-terminal-rugged.json

# 看价表
bomcheck book

# 字段说明
bomcheck schema
```

输出长这样（节选）：

```

  4G 模组   A7670C            1    49.00     49.98

  加工费-贴片                     7.79   820 点 × 0.0095 元/点
```

## 三档：钱该花在"不坏"上，不是花在"能刹车"上

| 档位 | 装什么 | 出厂成本 | 按档报价 |
|---|---|---|---|
| 精简 | 不装屏、不装摄像头、不串气路 | **¥263.18** | ¥526.37 |
| 标准 | 屏 + 4 路摄像头 + 气路执行 | **¥826.33** | ¥2,148.46 |
| 冗余 | 双 4G、双电源、光耦隔离、压铸车规壳、屏蔽线束，**刻意不装气阀** | **¥897.93** | ¥3,052.97 |

冗余档只比标准档贵 **¥71.60**，但把"不坏"买齐了，而且没动刹车管。

## 价表是你的，不是我的

`pricebook.json` 是明文 JSON，没有加密、没有联网、没有许可校验。

```json
"价格": {
  "A7670C": {"价": 49.0, "类别": "模组", "备注": "LTE Cat.1，下行 10M/上行 5M"}
},
"商务": {
  "不良率": 0.025,
  "报价倍数": {"精简": 2.0, "标准": 2.6, "项目制": 3.4},
  "红旗倍数": {"报价除出厂_红": 3.0, "报价除物料_红": 4.0}
}
```

按你自己渠道的询价改，改完再跑，倍数会跟着变。也可以把价表放到别处：

```bash
export BOMCHECK_PRICEBOOK=~/work/my-pricebook.json
```

**算法全开源，价格请自己填。** 价表是这行唯一真正有壁垒的东西，我不会替你编。

## 红旗判据

| 判据 | 阈值 | 含义 |
|---|---|---|
| 报价 ÷ 出厂成本 | ≥ 3.0 红 | 硬件之外的钱已经翻了两倍，那部分是什么得说清楚 |
| 报价 ÷ 出厂成本 | 2.2–3.0 黄 | 常规偏高，问一句就够 |
| 报价 ÷ 出厂成本 | < 1.6 蓝 | 可能不含安装/服务，便宜得可疑 |
| 报价 ÷ 物料成本 | ≥ 4.0 红 | 纯硬件口径不可能成立 |
| 单件价 > 价表 1.5 倍 | 灰 | 不是报价方的问题，是你自己采购被加价了 |

## 为什么做这个

做了几年硬件核价，见过最多的不是"卖太贵"，是**"没法比"**。

报价单给一个整机价，你把 BOM 拿过来逐项算，十次有八次算出来只有报价的三分之一——但你说不出口"你太贵"，因为你不知道那剩下三分之二里，哪些是合理的服务费，哪些不是。

这个工具只回答一个问题：**这个价，硬件部分值多少。**

剩下的是服务费。服务费要有服务费的说明。

---

## 边界

- 价表是 1000 台批量的参考区间，不是任何一家的真实采购价。批量、账期、渠道不同，差 30% 很正常。
- 不算模具费、不算研发人力、不算资金成本（账期 90 天和现结是两个生意）。
- BOM 里出现气阀/刹车/气路，引擎只提示，不评估安全性。本仓库不做安全认证，也不建议任何人照着自己改装制动系统。
- 不点名任何厂商。要说的是这一整类产品的定价逻辑，不是某一家。
